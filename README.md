# FinAI

**Full Stack**

**Code URL:** [GitHub Repository](https://github.com/iampraneeth1116/FinAI)  
**Hosted URL:** [Live Demo](https://finance-ai-demo.vercel.app)

**Tech Stack:** Next.js, React, Tailwind CSS, Express.js, Prisma, PostgreSQL, JWT Authentication, Google Gemini API, Recharts

Engineered an **AI-Powered Personal Finance Intelligence System (FinAI)** using Next.js, Express.js, Prisma, and Google Gemini API, enabling users to analyze spending patterns, manage budgets, simulate future financial decisions, and receive personalized AI-driven financial guidance.

## Features:

Implemented secure **JWT authentication** with **bcrypt password hashing** and protected API routes, ensuring reliable user access control and privacy for financial data.

Developed an interactive finance dashboard with **Recharts**, displaying total balance, income, expenses, recent transactions, monthly trends, and category-wise spending insights in a clean, responsive interface.

Built transaction and budget management workflows, including manual transaction entry, CSV upload support, monthly budget creation, budget progress tracking, and overspending indicators.

Integrated **Google Gemini API** to power an AI financial assistant that answers natural language questions using the user's real transaction data and generates personalized spending insights.

Created a scenario simulation module that projects future balances based on income changes, expense changes, one-time purchases, and selected time periods, helping users evaluate long-term financial decisions.

Designed account settings and profile management features, allowing users to update personal details and securely change passwords through authenticated backend APIs.
